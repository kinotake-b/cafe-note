# cafe-note

行ったカフェと行きたいカフェを、味や値段といっしょに残す個人用のカフェ帳．1つのHTMLファイル(`index.html`)だけでできている．

- 記録のデータは，開いた端末のブラウザの中にだけ保存される(このリポジトリには載らない)
- 機能:店名・エリア・評価・メモ・写真・注文と値段／コーヒーの記録(飲み物・豆・焙煎度・酸味苦味甘み)／検索・絞り込み／行きたいリスト／地図／統計
- バックアップは「統計」画面の「書き出す」から
- 地図は Leaflet と OpenStreetMap，住所検索は Nominatim(OpenStreetMap)を使う

## クラウド同期
- `sync.js` が Supabase と記録を同期する(メール+パスワードでログイン。レシピ帳と同じアカウント・同じプロジェクト)
- 設定の手順は `supabase/手順.md`、表を作るSQLは `supabase/setup.sql`
- `sync.js` は `recipe-app/` にも同じ内容で置いてある。直したら両方に反映する
