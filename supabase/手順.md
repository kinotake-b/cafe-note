# 同期を使えるようにする手順(最初の1回だけ)

レシピ帳とカフェ帳は、同じ Supabase プロジェクトと同じアカウントを使う。

1. https://supabase.com でアカウントを作り、「New project」でプロジェクトを作る(無料のプランでよい。リージョンは Tokyo)。
2. 左メニュー「SQL Editor」を開き、次の2つを、1つずつ貼り付けて Run する。
   - `recipe-app/supabase/setup.sql`(レシピ帳用)
   - `cafe-app/supabase/setup.sql`(カフェ帳用)
3. 左メニュー「Authentication」→「Sign In / Providers」→「Email」で、**「Confirm email」をオフ**にして保存する(オンのままだと、登録のあとに確認メールを開く手間が増える)。
4. 左メニュー「Project Settings」→「API」で、次の2つをコピーする。
   - Project URL(例: https://xxxx.supabase.co)
   - anon public のキー(長い文字列。公開してよい鍵)。**service_role のキーは使わない・渡さない。**
5. この2つを `cafe-app/sync.js` と `recipe-app/sync.js` の先頭の `SUPABASE_URL` と `SUPABASE_KEY` に入れる(両方、同じ値)。
6. 両方を commit → push する。
7. アプリの下のほうにある「クラウド同期」で、メールとパスワードを入れて「新規登録」。2台目以降は「ログイン」。
